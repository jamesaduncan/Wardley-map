A schema for Wardley maps

A Wardley map is a way of plotting the components of a busines, organisation or service on a chart in a way that cartographically sound, which is to say, position has meaning. Wardley maps can then be used to provide situational awareness in business.

Map
Property Type Required Cardinality Description
Component https://jamesaduncan.github.io/Wardley-map/schema/#component True Many Represents a component on a map. Could be a service, could be a technology, could be any of a number of things.
Component
Property Type Required Cardinality Description
Name https://schema.org/Text True One Represents the name of the component on a map
Evolution https://schema.org/Text True One Represents the evolution of a component on a map. Valid values are:
  • Genesis
  • Custom
  • Product
  • Commodity
Dependency https://schema.org/URL False Many A link to another component on a map.
